TURN 1 // INITIAL SPEC INJECTION 執筆セッション末尾に貼るだけ

【Step 1】2PS自動生成メタ・プロンプト

note記事やエッセイの執筆を終えたAI（Gemini等）のまさに同一セッションの末尾に、以下の構文をそのまま貼り付けて送信してください。AIが本文の文脈・感情・温度感およびあなたの語彙傾向を自動解析し、第1段階の「日本語設計書（Spec）」と第2段階の「確定英語コード（Render）」を一発出力します。

💡 運用の極意（なぜ一発で決まるのか）：

別チャットで要約を投げるのではなく、「本文を書いたそのチャットの末尾」に投げることで、AIの100万トークンの文脈記憶（KVキャッシュ）が働き、本文の空気感と100%同期した装丁が立ち上がります。初稿が出力されたら、上のタブで「Step 2」へ進んでください。

TURN 2 // ADAPTIVE LINTER, SIGNATURE GROUNDING & AUTO-FIX 品質自己監査 ＋ 作家性の物理接地 ＋ こだわり統合

【Step 2】作家性適応型・辞書内蔵確定Linter構文

AIがStep 1の初稿を出力したら、続けてこの構文を送信します。AIが6大基準で自己採点し、画一的な禁止ではなく、あなたの語彙の癖・作風を損なわないよう具体的な光や空間現象へ物理接地（Grounding）。さらにあなたが入力した情景イメージを100%定着させた100点満点確定コードへと自動リファクタリングします。

AIが自己監査時に判定する6大基準（100点満点）
1. 空間レイヤー分離 (20点)

奥の壁を排し、遠景への視線の抜けを確保しているか。

2. 存在理由（Why） (20点)

光や小道具の「存在理由」が本文と同期しているか。

3. 物理的単一拘束 (15点)

重要物に `strictly ONLY ONE` 排他ロックがあるか。

4. 厳格な排除拘束 (15点)

不要な壁、小道具、文字へのNegative指示があるか。

5. UI余白の死守 (15点)

手前右下25%が遮蔽物のないオープンフロアであるか。

6. 作家性の物理接地 (15点)

抽象語を排し、筆者の作風に調和する物理現象へ接地しているか。
