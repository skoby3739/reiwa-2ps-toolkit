# 🎨 reiwa-2ps-toolkit

**プロジェクト**: 令和レゾナンス（スコビー × Gemini）  
**概要**: note有料マガジン『画像生成の2PSメソッド』公式Webアセット・管制塔リポジトリ

## 📁 ディレクトリ構成

* `dashboard/` : プロジェクト統合管理管制塔（ダッシュボード）
* `tool/` : 記事④【即戦力ツール編】2PS自動生成＆自己監査ワークベンチ（10/7公開予定）
* `corpus/` : 記事⑤【実証原本集】連載全10話デザイン定義書＆確定コード（10/7公開予定）
* `releases/` : 配布用確定ZIPアーカイブ

## 🔒 限定公開ポリシー
本リポジトリのWebアセットは、全HTMLにおいて `<meta name="robots" content="noindex,nofollow">` を設定し、検索エンジンからの直接流入を遮断したシークレット運用を行っています。
